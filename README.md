# Collision Avoidance System

## Overview
This repository contains the complete source code for a full-stack Collision Avoidance System. This system includes authentication, abstract upload functionality, and NLP similarity detection.

## Project Structure
- **backend/**: Contains the server-side code.
- **frontend/**: Contains the client-side code.
- **docs/**: Documentation for the project.
- **tests/**: Automated tests for the application.

## Getting Started

### Prerequisites
- Node.js
- npm
- MongoDB (for database)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/OntimittaSanjana/project-collision-avoidance-system.git
   ```
2. Navigate into the directory:
   ```bash
   cd project-collision-avoidance-system
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Running the Application
1. Start the backend:
   ```bash
   cd backend
   node server.js
   ```
2. Start the frontend:
   ```bash
   cd frontend
   npm start
   ```

## Features
- User authentication
- File upload
- NLP similarity detection
